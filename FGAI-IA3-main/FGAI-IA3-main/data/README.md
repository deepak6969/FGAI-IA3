# Processed OPUS Books English French subset

These files are the exact 4,000 training, 200 validation, and 200 test pairs used in the reported Kaggle runs. They were retrieved from the completed [Kaggle preprocessing notebook](https://www.kaggle.com/code/eltonlewis/ict4403-english-french-data-preparation), version 2. `manifest.json` records cleaning and split settings.

Original textual dataset: [Helsinki-NLP OPUS Books en-fr](https://huggingface.co/datasets/Helsinki-NLP/opus_books/tree/main/en-fr). Please acknowledge OPUS and follow the source dataset's terms: it permits personal, educational, and research use, but does not grant commercial use or mass redistribution without permission.

Citation: Jörg Tiedemann, *Parallel Data, Tools and Interfaces in OPUS*, LREC 2012.
